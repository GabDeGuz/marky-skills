## ⚙️ Installation & Usage

### 1. Linking into Global Antigravity / Gemini Customizations
To make all skills globally accessible in your Antigravity IDE:
```powershell
# Copy desired category or all skills to global config
Copy-Item -Recurse -Force "C:\Users\Nitro V15\Documents\GitHub\marky-skills\*" "C:\Users\Nitro V15\.gemini\config\skills\"
```

### 2. Linking into a Specific Project Workspace
To use in any repository workspace:
```bash
# Place under .agents/skills/ or .gemini/skills/
mkdir -p .agents/skills
cp -r /path/to/marky-skills/<category>/<skill-name> .agents/skills/
```

### 3. Using in Cursor IDE
Copy desired skills directly into `.cursor/skills/` within your home directory or active workspace root.
