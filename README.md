## ⚡ Instant 1-Click Install for Friends

Your friends can equip these skills into any project workspace or global AI setup with a single command — **no manual downloading or copying needed**!

### 🌟 1. Install Must-Haves Only (Recommended Starter Kit)
Installs the **18 essential full-stack skills** (React, Next.js, APIs, SQL tuning, security, git safety, Karpathy rules, TDD):
```bash
# If installed via npm:
npx marky-skills must-have

# Or directly from your GitHub repository:
npx github:YOUR-USERNAME/marky-skills must-have
```

---

### 🚀 2. Install ALL Skills (Complete Collection)

### 🌐 4. Target Options (Where to Install)

By default, skills are installed into the active project workspace (`.agents/skills`). You can also specify other destinations:

```bash
# Install globally into your AI IDE config (~/.gemini/config/skills):
npx marky-skills must-have --global

# Install into Cursor IDE (.cursor/skills):
npx marky-skills must-have --cursor

# Install into Claude Code (.claude/skills):
npx marky-skills must-have --claude

# Install into a custom directory:
npx marky-skills must-have --target ./custom-folder
```

---

### 💡 5. Interactive Menu Mode
Simply run the command with no arguments to get an interactive terminal menu:
```bash
npx marky-skills
```
